# moldmeta

Mold digests and meta fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/moldmeta/

## Install / run

```bash
git clone https://github.com/theworker02/moldmeta.git
cd moldmeta
node src/cli.js
node --test
```
